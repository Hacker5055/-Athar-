# تطبيق أثَر (Athar App)

تطبيق إسلامي حديث ومتكامل يركز على **التخصيص، الذكاء الاصطناعي، والجانب العملي والتفاعلي**، جامعاً بين الاحتياجات الروحية والإنتاجية اليومية للمسلم المعاصر.

## المميزات الرئيسية
1. **الحفظ والمراجعة الذكية:** مصحح التلاوة الصوتي بالذكاء الاصطناعي، خطة المراجعة بنظام التكرار المتباعد (Spaced Repetition)، والربط البصري الموضوعي للآيات (خرائط ذهنية).
2. **المعايشة والفهم العميق:** الباحث الدلالي والشعوري للقرآن والسنة، وبطاقة السياق التفاعلية وأسباب النزول.
3. **إنتاجية المسلم وتنظيم الحياة:** منظم اليوم حول الصلاة (Salah-Centric Planner)، محاكي الوضع الهادئ التلقائي في المسجد (Geofencing)، وأذكار ذكية معتمدة على المستشعرات.
4. **المعاملات المالية والشرعية:** ماسح العقود بالذكاء الاصطناعي لكشف الشبهات واقتراح البدائل، حاسبة الزكاة الذكية، وحاسبة المواريث البصرية.
5. **المجتمع والجيل الجديد:** خريطة مرافق المساجد التفاعلية المجتمعية، ختمات وتحديات العائلة التنافسية، والقصص الأخلاقية التفاعلية للأطفال.
6. **دراسة الجدوى الفنية:** تقرير تفصيلي دقيق يقيم إمكانية إضافة الميزات وتحدياتها التقنية والتنظيمية.
