# تطبيق أثَر (Athar App) - التجربة الإسلامية التفاعلية الحديثة

تطبيق إسلامي رائد يركز على **التخصيص، الذكاء الاصطناعي، والجانب العملي والتفاعلي اليومي** للمسلم المعاصر، متجاوزاً التطبيقات النمطية التقليدية.

---

## 📊 أولاً: تحليل الجدوى الفنية للميزات (الميزات القابلة للإضافة والميزات الصعبة مع الأسباب)

### 1. الميزات القابلة للإضافة والتنفيذ المباشر (Feasible Features)
| الميزة | إمكانية التنفيذ | السبب الفني والتنفيذي |
| :--- | :---: | :--- |
| **خطة مراجعة بنظام التكرار المتباعد (Spaced Repetition)** | قابلة جداً (عالية) | تطبيق خوارزميات التكرار المتباعد المعتمدة (مثل SuperMemo SM-2 المستخدمة في Anki) عبر جدولة زمنية مبنية على معدلات أخطاء الحفظ، وتخزينها محلياً أو سحابياً بكفاءة. |
| **الربط البصري والذهني للآيات (الخرائط الذهنية)** | قابلة جداً (عالية) | تقسيم السور لمواضيع ومحاور عبر نماذج بيانات بصرية (Node Graph أو Cards) تربط بين أرقام الآيات والموضوع بأسلوب يرسخ التسلسل الذهني دون تكلفة بنية تحتية معقدة. |
| **الباحث الدلالي والنفسي للقرآن والسنة** | قابلة (عالية) | الاعتماد على تضمين النصوص والبحث الدلالي الموجه (Vector Search & Text Embeddings) مثل OpenAI Embeddings أو النماذج مفتوحة المصدر لربط المشاعر الإنسانية بالنصوص الشرعية والتفاسير. |
| **التفسير التفاعلي وسياق النزول** | قابلة جداً (عالية) | بناء بطاقات سياقية (Context Cards) تستعرض أسباب النزول المعتمدة، نوع العهد (مكي/مدني)، والمعاني اللغوية للكلمات الغريبة في تصميم مرئي سريع الاستجابة. |
| **منظم اليوم حول الصلاة (Salah-Centric Planner)** | قابلة جداً (عالية) | حساب مواقيت الصلاة الفلكية بدقة وفق إحداثيات المدينة، وتوزيع المهام ديناميكياً على الفترات البينية ("ما بين الفجر والشروق"، "ما بين الظهر والعصر"...). |
| **حاسبة المواريث والزكاة التفاعلية** | قابلة جداً (عالية) | صياغة الخوارزميات الحسابية الفقهية بدقة، وربط أسعار الذهب والفضة اللحظية عبر واجهات برمجة تطبيقات مالية (Market APIs) لتحديد بلوغ النصاب تلقائياً. |
| **خريطة مرافق المساجد التشاركية (Crowdsourced Map)** | قابلة (عالية) | استخدام خرائط مفتوحة المصدر مثل OpenStreetMap أو Google Maps مع توفير واجهة تقييم مجتمعي للخدمات (مصلى السيدات، كراسي كبار السن، النظافة). |
| **ختمات العائلة والأصدقاء والقصص الأخلاقية للأطفال** | قابلة (عالية) | غرف خاصة مشتركة لمتابعة الورد والختمات بدون رياء مع إمكانية إخفاء الهوية، وقصص تفاعلية تفرعية (Branching Scenarios) تغرس الأخلاق النبوية الشريفة. |

### 2. الميزات الصعبة أو المعقدة تقنياً وتنظيمياً (Challenging Features)
| الميزة | مستوى الصعوبة | الأسباب الفنية والتنظيمية |
| :--- | :---: | :--- |
| **مصحح التلاوة الصوتي المباشر للتجويد (AI Recitation Corrector)** | صعبة جداً تقنياً | **1) دقة النموذج الصوتي ومخارج الحروف:** أحكام التجويد (المدود بالحركات الزمنية الدقيقة، الغنن ومراتبها، القلقلة، والإدغام) تتطلب نماذج معالجة إشارات صوتية (Audio Signal Processing & Phoneme Recognition) متخصصة وعالية التكلفة، غير متوفرة في محركات تحويل الصوت لنص التقليدية (ASR).<br>**2) الضوضاء واللكنات وتفاوت النبرات:** اختلاف نبرات القراء والضوضاء المحيطة ينتج عنه نسبة خطأ وملاحظات خاطئة (False Positives) قد تربك المتعلم. |
| **الوضع الصامت التلقائي في المسجد بالخلفية (Geofencing & Background Silent Mode)** | صعبة ومعقدة نظامياً | **1) قيود أذونات أنظمة التشغيل (OS Restrictions):** قيود صارمة في أحدث إصدارات Android و iOS تمنع التطبيقات في الخلفية من تغيير إعدادات الصوت والجرس تلقائياً بدون تدخل صريح للمستخدم، لأسباب أمنية وحماية خصوصية المستخدم.<br>**2) استهلاك الطاقة ودقة الإشارة:** تشغيل الـ GPS عالي الدقة في الخلفية يستهلك البطارية بسرعة، وإشارة الأقمار الصناعية تضعف أو تنعكس داخل المباني والخرسانات، مما يؤدي لاكتشاف متأخر أو خاطئ. |
| **أذكار ذكية تلقائية عبر المستشعرات (Automatic Sensor-Based Athkar)** | صعبة من حيث دقة السياق | **1) التنبيهات الكاذبة (False Triggers):** الربط التلقائي بالبلوتوث قد يكون لسماعة منزلية وليس سيارة، أو المرور بالقرب من مول دون دخوله قد يطلق دعاء السوق بشكل مزعج.<br>**2) قيود الشاشة المقفلة:** لا تسمح أنظمة التشغيل بعرض واجهات أو بطاقات قراءة مباشرة فوق شاشة القفل عند تغير المستشعر دون تفاعل المستخدم، بل تقتصر على إشعار عادي قد يتجاهله المستخدم. |
| **ماسح العقود والمعاملات المالية الشرعي (AI Contract Legal Scanner)** | صعبة وحرجة تنظيمياً وفقهياً | **1) المسؤولية الشرعية والقانونية:** العقود المالية والقانونية حساسة جداً والاعتماد التلقائي على الذكاء الاصطناعي قد يُفضي إلى فتاوى خاطئة أو إغفال شروط ضمنية دقيقة مما يرتب مسؤولية قانونية وشرعية جسيمة.<br>**2) تنوع الصياغات والمذاهب:** اختلاف الصياغات القانونية المحلية والمدارس الفقهية يتطلب مراجعة بشرية متخصصة ومستمرة بدلاً من الحكم الآلي المطلق. |

## 🛠️ البنية التقنية لتطبيق أثر

- **الواجهة الأمامية:** React 19، Vite 6، Tailwind CSS، Lucide React Icons.
- **التصميم:** دعم كامل لنمط RTL والخطوط العربية (Tajawal)، ولوحة ألوان إسلامية عصرية (الزمردي، التركواز، والأزرق الداكن).
- **أقسام التطبيق الرئيسية:**
  1. قسم الحفظ والمراجعة الذكية (مصحح التلاوة، التكرار المتباعد، الخرائط الذهنية).
  2. قسم المعايشة والفهم العميق (الباحث النفسي والدلالي، بطاقة سياق الآية).
  3. قسم إنتاجية المسلم (منظم الصلاة، محاكي الوضع الصامت، الأذكار الذكية).
  4. قسم المعاملات المالية والشرعية (ماسح بنود العقود، حاسبة الزكاة، حاسبة المواريث).
  5. قسم المجتمع والجيل الجديد (خريطة مرافق المساجد، ختمات الورد، قصص الأطفال التفاعلية).
  6. قسم دراسة الجدوى الفنية وتقييم الميزات الهندسية.
