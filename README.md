## 🛠️ البناء

```bash
cd android
./gradlew assembleDebug      # يحتاج JDK ١٧ و Android SDK
./gradlew testDebugUnitTest  # ٦٠٤ اختبارًا
```

- **CI هو المُجمِّع الحقيقيّ**: كلُّ pushٍ يبني APKَين (تصحيحٌ
  وإصدارٌ) وينشرهما في الإصدار.
- **نصُّ القرآن لا يُرفع إلى Git**: يُنزَّل في CI من مصدره
  المرخَّص، والمصادرُ كلُّها موثّقةٌ في `docs/09`.
- **الخطوطُ مُرفَقةٌ داخل التطبيق** (~١٫١ ميجابايت) ورخصتُها
  (OFL) في `assets/licenses/`.
