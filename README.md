```bash
cd prototype
python3 -m http.server 3000
# افتح http://localhost:3000
```

- بدّل بين **العربية / English / Français** (الاتجاه RTL/LTR بيتغير فورًا).
- بدّل **الفاتح / الداكن**، و**المدينة**، و**طريقة حساب المواقيت**.
- فعّل **«ملاحظات التصميم»** عشان تشوف الدبابيس المرقّمة وشرح كل قرار تصميم.

المواقيت والتاريخ الهجري واتجاه القبلة **محسوبة فلكيًا فعليًا** في المتصفح — مش أرقام ثابتة.

## 🎯 الفكرة في سطرين

التطبيقات الإسلامية الحالية إما **متخصصة جدًا** (مصحف لوحده، مواقيت لوحدها) أو **مزعجة** (إعلانات، نت دائم).
**أثر** بيجمع الأساسيات في تطبيق واحد، شغال أوفلاين، بلا إعلانات، ويضيف حاجة ناقصة: **متتبع «أثري»** اللي يخلي الاستمرارية اليومية مرئية.

### الركائز الثلاث
1. **الدقة** — مواقيت صحيحة بـ ١٠+ طرق حساب ومذهب وتعديل يدوي.
2. **العمق** — قرآن كامل أوفلاين: نص عثماني، تفسير، ترجمات، تلاوات، بحث، حفظ.
3. **الاستمرارية** — «أثري»: عبادات يومية + ختمة + سلسلة أيام.

### ما لن نفعله أبدًا
❌ إعلانات · ❌ بيع بيانات · ❌ فتاوى آلية · ❌ حساب إجباري · ❌ محتوى عبادة خلف دفع
