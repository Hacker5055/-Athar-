# تطبيق أثَر (Athar App) 🌙✨

**التجربة الإسلامية الحديثة المرتكزة على التخصيص، الذكاء الاصطناعي، والإنتاجية اليومية للمسلم.**

---

## 📌 نبذة عن المشروع
تطبيق **"أثَر"** هو تطبيق ويب عصري مبني باستخدام **React + Vite + Tailwind CSS**، يهدف إلى الارتقاء بالتطبيقات الإسلامية من مجرد أدوات تقليدية لعرض المواقيت والأذكار إلى منظومة ذكية متكاملة تتفاعل مع مشاعر المستخدم، تنظم يومه حول الصلاة، تساعده في حفظ وتدبر القرآن، وتوفر له استشارات مالية وفقهية استرشادية.

---

## 📊 دراسة وتقييم جدوى الميزات (Feasibility Analysis)

### 1. الميزات القابلة للإضافة والتطبيق الفوري (High Feasibility & Value)

| الميزة | التصنيف | الجدوى والسبب التقني |
| :--- | :--- | :--- |
| **خطة مراجعة بالتكرار المتباعد (Spaced Repetition)** | الحفظ والمراجعة | سهلة التطبيق باستخدام خوارزميات رياضية مجرّبة (مثل SuperMemo SM-2 أو FSRS) مع حفظ سجل تقدم المستخدم لتحديد التوقيت الأمثل للمراجعة قبل النسيان. |
| **الخرائط الذهنية ومحاور السور** | الحفظ والتدبر | تعتمد على بنية بيانات هيكلية تربط آيات كل سورة بمحاورها وموضوعاتها مع واجهات تفاعلية جذابة توضح تسلسل الأفكار والقصص. |
| **الباحث الدلالي والنفسي للقرآن والسنة** | المعايشة والفهم | يمكن تطبيقه بكفاءة عالية عبر تقنيات البحث بالمتجهات (Vector Search & Text Embeddings) لربط الموقف أو الشعور النفسي بالآيات والأحاديث المناسبة. |
| **بطاقة السياق والتفسير التفاعلية** | التدبر والفهم | توفير بطاقات معلومات سريعة تظهر عند النقر على أي آية تضم أسباب النزول كقصة قصيرة، العهد (مكي/مدني)، والمعاني اللغوية. |
| **منظم اليوم حول الصلاة (Salah-Centric Planner)** | إنتاجية المسلم | حساب مواقيت الصلاة فلكياً وربط المهام بفترات الصلوات (بين الفجر والشروق، بين الظهر والعصر...) مع إعادة جدولة ديناميكية لتغير المواقيت. |
| **حاسبة الزكاة المتطورة** | المعاملات المالية | قواعد فقهية ورياضية محددة لحساب زكاة الأسهم والذهب والعملات والربط بأسعار الذهب اللحظية. |
| **حاسبة المواريث الشرعية البصرية** | المعاملات المالية | خوارزميات علم الفرائض (حساب أنصبة أصحاب الفروض والعصبة) مع عرض بياني والدليل الشرعي لكل وارث. |
| **خريطة مرافق المساجد التفاعلية** | المجتمع | تعتمد على واجهات الخرائط (OpenStreetMap) ونظام تقييم مساهماتي لمصليات النساء وتوفر كراسي كبار السن ومداخل الهمم. |
| **ختمات وتحديات العائلة والأصدقاء** | المجتمع | غرف خاصة بقواعد بيانات فورية، مع ميزة إخفاء الهوية حفاظاً على الإخلاص ومنع الرياء. |
| **القصص التفاعلية للأطفال (اختر مسارك)** | الجيل الجديد | سيناريوهات متفرعة تفاعلية (Branching Story) تغرس القيم النبوية والأخلاقية بأسلوب ممتع. |

### 2. الميزات الصعبة أو المقيدة بنظام التشغيل مع الأسباب والبدائل

#### 🔴 مصحح التلاوة الصوتي للتجويد المباشر (AI Tajweed Recitation Corrector)
- **الأسباب والتحديات:**
  1. **صعوبة تحليل أحكام التجويد صوتياً:** نماذج التعرف على الكلام التقليدية لا تميز أزمنة المدود بدقة الأجزاء من الثانية، ولا ترصد مراتب الغنة، أو تفخيم/ترقيق الراءات ومخارج الحروف الدقيقة (كالضاد والظاء).
  2. **تنوع الأصوات والضوضاء:** قد تسبب الإنذارات الخاطئة (False Positives) إرباكاً للحافظ وتصحيحاً غير صحيح لكلمات القرآن.
  3. **تكلفة الحوسبة الفورية:** تتطلب خوادم معالجة إشارات صوتية سريعة ومكلفة.
- **الحل البديل المنفّذ في "أثر":** تطبيق نظام هجين؛ فحص التشكيل الفوري عبر الذكاء الاصطناعي مع إتاحة إرسال التسجيلات لمعلمين ومقرئين مجازين للتصحيح الموثوق.

#### 🔴 الوضع الصامت التلقائي في المسجد في الخلفية (Background Geofencing & Silent Mode)
- **الأسباب والتحديات:**
  1. **قيود أنظمة التشغيل (iOS & Android):** تمنع شركة Apple (iOS) تماماً أي تطبيق عادي من التحكم بالوضع الصامت للجهاز برمجياً لأسباب تتعلق بالخصوصية، كما تفرض Google شروطاً صارمة على أذونات `Do Not Disturb`.
  2. **استنزاف البطارية وضعف إشارة GPS:** التتبع المستمر يستنزف الطاقة، والمساجد مبانٍ خرسانية معزولة تضعف فيها إشارة الأقمار الصناعية.
- **الحل البديل المنفّذ في "أثر":** إرسال إشعار تفاعلي فوري عند الاقتراب من المسجد أو وقت الصلاة بضغطة زر واحدة لتفعيل وضع التركيز (Focus Mode).

#### 🔴 أذكار ذكية تلقائية عبر المستشعرات والبلوتوث في الخلفية
- **الأسباب والتحديات:**
  1. **منع النوافذ المنبثقة من الخلفية:** تمنع أنظمة التشغيل تشغيل شاشات كاملة أثناء قفل الهاتف.
  2. **الإنذارات الخاطئة:** الاقتران بسماعة بلوتوث منزلية قد يظنه التطبيق سيارة، أو المرور بجانب مول يظنه دخولاً للسوق.
- **الحل البديل المنفّذ في "أثر":** الاعتماد على واجهات الأنشطة المجدولة وإرسال إشعار لطيف وموجز في شريط الإشعارات بدعاء السياق.

#### 🔴 ماسح العقود والمعاملات المالية الشرعي الآلي (AI Shariah Contract Scanner)
- **الأسباب والتحديات:**
  1. **المسؤولية الشرعية والقانونية:** لا يجوز إسناد إصدار الأحكام والفتاوى الشرعية لنماذج الذكاء الاصطناعي بشكل قطعي لتجنب تضليل المستخدم.
  2. **تعقيد الصياغات القانونية المحلية:** اختلاف القوانين واللوائح التنظيمية بين الدول.
- **الحل البديل المنفّذ في "أثر":** أداة استرشادية توعوية تسلط الضوء على البنود الشائعة (مثل غرامات التأخير أو الجهالة) وفقاً لمعايير الأيوفي (AAOIFI) مع التنبيه بضرورة الرجوع للمفتي المختص.

## 🛠️ البنية التقنية للتطبيق
- **Frontend Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (Dark Mode Slate / Emerald / Amber theme)
- **Icons:** Lucide React
- **Design Principles:** Arabic RTL, Responsive mobile-first, Accessible UI
