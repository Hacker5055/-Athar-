# تطبيق "أثَر" (Athar) - التجربة الإسلامية الحديثة بالذكاء الاصطناعي والإنتاجية

تطبيق **أثَر** هو جيل جديد من التطبيقات الإسلامية التفاعلية التي تتجاوز الأساسيات التقليدية (المواقيت، المصحف، الأذكار) لتركز على **التخصيص، الذكاء الاصطناعي، والجانب العملي التفاعلي** في حياة المسلم اليومية.

---

## 📌 أقسام وميزات تطبيق "أثَر"

### 1. الحفظ والمراجعة الذكية
- **مصحح التلاوة الصوتي:** الاستماع لتلاوة المستخدم وتنبيهه فوراً على أخطاء التشكيل وأحكام التجويد (المدود، الغنة، القلقلة) مع شرح الحكم.
- **خطة مراجعة بالتكرار المتباعد (Spaced Repetition):** جدولة ذكية لتحليل السور التي يخطئ فيها المستخدم وتذكيره بمراجعتها قبل نسيانها وفق خوارزميات التكرار المتباعد.
- **الربط البصري والذهني للآيات (خرائط ذهنية):** تقسيم السور إلى محاور وقصص مترابطة بصرياً لتثبيت الحفظ وعدم الخلط بين المتشابهات.

### 2. المعايشة والفهم العميق
- **الباحث الدلالي والنفسي:** البحث بالمشاعر والمواقف اليومية ("أشعر بقلق من المستقبل"، "تعرضت للظلم") لاستخراج الآيات والأحاديث والتوجيهات العملية المناسبة.
- **التفسير التفاعلي وبطاقة السياق:** بطاقة غنية عند النقر على أي آية توضح سبب النزول كقصة قصيرة، العهد (مكي/مدني)، ومعاني الكلمات الغريبة بصرياً.

### 3. إنتاجية المسلم وتنظيم الحياة
- **منظم اليوم حول الصلاة (Salah-Centric Planner):** تقسيم اليوم لمهام بين الصلوات ("ما بين الفجر والشروق"، "ما بين الظهر والعصر") وربطها ديناميكياً بالمواقيت.
- **محاكي الوضع الهادئ التلقائي في المسجد (Geofencing):** تفعيل الوضع الصامت تلقائياً عند الاقتراب من نطاق المسجد الجغرافي.
- **أذكار ذكية مرتبطة بالسياق:** تنبيهات ذكية متصلة بالمستشعرات (دعاء الركوب عند بلوتوث السيارة، دعاء السفر للسرعات العالية، دعاء السوق عند المولات).

### 4. المعاملات المالية والشرعية
- **ماسح العقود والمعاملات المالية:** فحص بنود عقود العمل والقروض والتقسيط والتنبيه على الشروط غير الشرعية (غرامات التأخير الربوية، الجهالة) واقتراح البديل الشرعي.
- **حاسبة الزكاة والمواريث:** حاسبة تفاعلية لزكاة الأسهم والذهب والعملات، وتقسيم الميراث خطوة بخطوة مع الدليل الشرعي لكل نصيب.

### 5. المجتمع والعمل الجماعي
- **خريطة مرافق المساجد التفاعلية (Crowdsourced Map):** تقييم المصلين لخدمات المسجد (مصلى سيدات، نظافة، كراسي كبار السن، مدخل ذوي الاحتياجات الخاصة).
- **ختمات وتحديات العائلة والأصدقاء:** غرف خاصة لمتابعة ورد التلاوة والتنافس الإيماني مع الحفاظ على الخصوصية والإخلاص دون رياء.

### 6. قسم الأطفال والجيل الجديد
- **القصص الأخلاقية التفاعلية (اختر مسارك بأخلاقك):** قصص وسيناريوهات تفاعلية يختار فيها الطفل التصرف الأخلاقي الصحيح ويكتشف نتائجه اقتداءً بالنبي ﷺ.

## 📊 دراسة الجدوى والتقييم الفني للميزات (Feasibility Report)

| الميزة | إمكانية التطبيق | الأسباب والتحليل التقني |
| :--- | :---: | :--- |
| **خطة التكرار المتباعد** | قابلة للإضافة بسهولة | خوارزميات رياضية مثبتة (SM-2 / FSRS) وسهولة التخزين المحلي والسحابي. |
| **الخرائط الذهنية للقرآن** | قابلة للإضافة بسهولة | هيكلة بيانات شجرية وموضوعية ورسومات بصرية واضحة. |
| **الباحث الدلالي والنفسي** | قابلة للإضافة بكفاءة | تقنيات التضمين اللغوي والبحث الشعاعي (Vector Search / Embeddings). |
| **التفسير وبطاقة السياق** | قابلة للإضافة بسهولة | قواعد بيانات موثقة لأسباب النزول والمعاني البصرية. |
| **منظم اليوم حول الصلاة** | قابلة للإضافة بسهولة | حسابات فلكية معيارية لمواقيت الصلاة وإعادة جدولة المهام ديناميكياً. |
| **حاسبة المواريث والزكاة** | قابلة للإضافة بسهولة | خوارزميات فقهية محددة وربط بأسعار الذهب عبر APIs مالية. |
| **خريطة مرافق المساجد** | قابلة للإضافة بسهولة | نمط البيانات التشاركية (Crowdsourcing) عبر خدمات الخرائط المفتوحة. |
| **الختمات التنافسية** | قابلة للإضافة بسهولة | غرف خاصة بقواعد بيانات آنية (Realtime DB) مع حماية الخصوصية. |
| **قصص الأطفال التفاعلية** | قابلة للإضافة بسهولة | سيناريوهات قصصية متفرعة (Branching Narrative) جذابة وتفاعلية. |
| **مصحح التلاوة الصوتي للتجويد** | **صعبة ومعقدة تقنياً** | تتطلب نماذج صوتية فائقة التخصص للتمييز الدقيق بين مخارج الحروف والمدود والغدد الزمنية، وتتأثر بالضوضاء واللكنات وتستهلك موارد المعالج. |
| **الوضع الصامت التلقائي (Geofencing)** | **صعبة تقنياً وتنظيمياً** | قيود أنظمة التشغيل الصارمة (iOS & Android) التي تمنع التطبيقات في الخلفية من تغيير نمط الصوت تلقائياً، واستنزاف البطارية وضعف إشارة GPS داخل المساجد. |
| **أذكار المستشعرات التلقائية** | **صعبة تنظيمياً** | حظر النوافذ المنبثقة من الخلفية عند قفل الشاشة، وارتفاع معدل الإنذارات الخاطئة (False Positives). |
| **ماسح العقود المالي الذكي** | **صعبة وحرجة شرعاً وقانونياً** | المسؤولية الفقهية والقانونية في حال وقوع أخطاء، واختلاف الصياغات القانونية المحلية التي تتطلب مراجعة بشرية مستمرة. |

## 🛠️ تقنيات التطوير والتشغيل

- **الواجهة:** React + Vite
- **التصميم:** Tailwind CSS + Lucide Icons
- **اللغة:** JavaScript (ESNext)
- **التشغيل محلياً:**
  ```bash
  npm install
  npm run dev
  ```
- **بناء حزمة الإنتاج:**
  ```bash
  npm run build
  ```
