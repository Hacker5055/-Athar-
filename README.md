# تطبيق أثَر (Athar App) - التجربة الإسلامية الحديثة بالذكاء الاصطناعي والإنتاجية

تطبيق إسلامي رائد ونوعي يهدف إلى تجاوز نمطية التطبيقات التقليدية (التي تقتصر على مواقيت الصلاة والمصحف والأذكار) ليركز على **التخصيص الفردي، الذكاء الاصطناعي، والجانب العملي التفاعلي** في حياة المسلم اليومية.

---

## 📑 أولاً: دراسة الجدوى وتصنيف الميزات (الميزات الممكنة والميزات الصعبة مع الأسباب)

تم إجراء دراسة تقنية وهندسية شاملة لكل ميزة من الميزات المقترحة لتحديد مدى قابليتها للتنفيذ الفوري، وتبيان الميزات المعقدة وأسباب صعوبتها:

### 1. الميزات القابلة للإضافة والتطبيق الفوري (High Feasibility & Immediate Delivery)

| الميزة | مجال التطبيق | آلية التنفيذ والجدوى |
| :--- | :--- | :--- |
| **خطة مراجعة بالتكرار المتباعد (Spaced Repetition)** | الحفظ والمراجعة | تعتمد على خوارزميات رياضية مثبتة (مثل SM-2 أو FSRS) لحساب منحنى النسيان وجدولة المراجعة، وتخزين سجل الأخطاء محلياً أو سحابياً. |
| **الربط البصري والذهني للآيات (الخرائط الذهنية)** | الحفظ وتثبيت المتشابهات | هيكلة بيانات موضوعية شجرية (Hierarchical Tree) للسور وتقسيمها لمحاور وقصص بصرية واضحة تحل مشكلة التيه والخلط في السور الطويلة. |
| **الباحث الدلالي والنفسي (القرآن والسنة لحالتك)** | المعايشة والفهم العميق | استخدام نماذج تضمين النصوص (Vector Embeddings) والبحث المتجهي لربط مشاعر المستخدم بآيات المواساة والتوجيه النبوي الصحيح بدقة فائقة. |
| **التفسير التفاعلي والسياقي (بطاقة الآية)** | المعايشة والفهم العميق | ربط نصوص التفاسير الموثوقة وأسباب النزول في شكل قصة سياقية ومعانٍ بصرية للكلمات الغريبة في بطاقة جذابة وسريعة. |
| **منظم اليوم المعتمد على الصلاة (Salah-Centric Planner)** | إنتاجية المسلم | استخدام مكتبات الحساب الفلكي للمواقيت (Adhan algorithms) لربط فترات اليوم بالصلوات الخمس بدلاً من الساعات الجافة. |
| **حاسبة المواريث والزكاة التفاعلية** | المعاملات المالية | خوارزميات فقهية محكمة وفق علم الفرائض الشرعي مع ربط أسعار الذهب اللحظية لحساب النصاب الشرعي (85 جرام). |
| **خريطة مرافق المساجد التفاعلية (Crowdsourced Map)** | المجتمع والعمل الجماعي | خريطة تشاركية عبر خرائط تفاعلية وتقييمات المصلين للمرافق (مصلى السيدات، نظافة الوضوء، كراسي كبار السن، مدخل ذوي الهمم). |
| **ختمات وتحديات العائلة والأصدقاء وقصص الأطفال** | المجتمع والجيل الجديد | قواعد بيانات لحظية (Realtime DB) للختمات الجماعية مع خيار إخفاء الهوية إخلاصاً، وشجرة خيارات تفاعلية للقصص الأخلاقية. |

---

### 2. الميزات الصعبة أو المعقدة تقنياً وتنظيمياً مع أسبابها التفصيلية والبدائل الذكية

#### 1) مصحح التلاوة الصوتي المباشر للتجويد بالذكاء الاصطناعي
* **سبب الصعوبة:**
  * **تحدي دقة النموذج التجويدي:** نماذج التعرف الصوتي العامة (Speech-to-Text) تتعرف على الكلمات العادية ولا تفهم دقائق علم التجويد (مثل مقادير المد الطبيعي والفرعي، مراتب الغنة، تفخيم وترقيق الراء، ومخارج الحروف المتقاربة كالضاد والظاء). تدريب نموذج صوتي متقن يتطلب آلاف الساعات الترتيلية المعلمة بدقة ومعالجة إشارات صوتية (DSP) معقدة.
  * **الضوضاء وتنوع المقامات واللكنات:** أي تشويش محيط أو تفاوت في سرعة القراءة قد يؤدي إلى إنذارات خاطئة (False Positives) تسبب حرجاً وإرباكاً للحافظ في كتاب الله.
* **البديل الهندسي الذكي في تطبيق أثر:** فحص الكلمات وترتيبها ومطابقتها نصياً وصوتياً مع تقديم مقارنة فورية بترتيل مشايخ متقنين وتوفير خيار إرسال التلاوة للمراجعة البشرية.

#### 2) الوضع الهادئ التلقائي في المسجد بالخلفية (Geofencing & Background Silent Mode)
* **سبب الصعوبة:**
  * **قيود نظام Apple iOS القاطعة:** تمنع شركة أبل كلياً وبشكل صارم أي تطبيق في الخلفية من تغيير مفتاح الصوت/الرنين أو التحكم في نمط عدم الإزعاج (Do Not Disturb) لحماية خصوصية وتجربة المستخدم.
  * **قيود Android الحديثة واستنزاف البطارية:** يتطلب صلاحيات حرجة قد يرفضها متجر Google Play، كما أن تشغيل GPS مستمر بالخلفية يفرغ البطارية سريعاً، وتضعف الإشارة داخل المباني الخرسانية للمساجد مما قد يؤخر التفعيل أو يطلقه في المكان الخطأ.
* **البديل الهندسي الذكي في تطبيق أثر:** إرسال إشعار تفاعلي فوري عند الوصول للمسجد بضغطة زر واحدة للتفعيل، أو التكامل مع أتمتة أنماط التركيز (Siri Shortcuts & Android Focus Modes).

#### 3) الأذكار الذكية التلقائية بالمستشعرات (السرعة، البلوتوث، الموقع)
* **سبب الصعوبة:**
  * **حظر النوافذ المنبثقة:** تمنع أنظمة التشغيل التطبيقات من الاستحواذ على الشاشة وعرض أذكار مفاجئة أثناء إغلاق الهاتف إلا عبر إشعارات دفع عادية.
  * **كثرة الإنذارات الخاطئة (False Triggers):** قد يقترن الهاتف بسماعة في المنزل وليس سيارة، أو يمر القطار بمول دون دخوله مما يجعل الإشعارات التلقائية مزعجة.
* **البديل الهندسي الذكي في تطبيق أثر:** توفير ودجات ذكية (Widgets) تفاعلية على الشاشة الرئيسية وشاشة القفل تتغير تلقائياً حسب السياق بلمسة واحدة دون إزعاج.

#### 4) ماسح العقود والمعاملات وإصدار الفتاوى بالذكاء الاصطناعي
* **سبب الصعوبة:**
  * **المسؤولية الشرعية والقانونية ومخاطر الهلوسة:** صياغات العقود تتشابك محلياً وتخضع لضوابط البنوك المركزية. الاعتماد الكلي على الذكاء الاصطناعي في الفتوى ينطوي على مخاطرة جسيمة إذا حلل عقداً فاسداً أو حرم معاملة صحيحة.
* **البديل الهندسي الذكي في تطبيق أثر:** فحص استرشادي تحذيري يبرز الكلمات الحساسة (غرامات تأخير، شروط جزائية مفتوحة) مع اقتراح البدائل المعتمدة فقهياً والتنبيه بأن الأداة للتوعية فقط.

## 🚀 ثانياً: ميزات ووحدات تطبيق "أثَر"

يضم التطبيق واجهات تفاعلية مبنية بأحدث تقنيات الويب:

1. **قسم الحفظ والمراجعة الذكية (`QuranMemorization`):**
   * مصحح تلاوة صوتي تفاعلي يحلل الآيات وملاحظات التجويد.
   * بطاقات المراجعة بنظام التكرار المتباعد (Spaced Repetition) مع تسجيل تقييم الاستدعاء (صعب/جيد/ممتاز).
   * خرائط ذهنية شجرية للمحاور الموضوعية لسور القرآن (سورة الملك وسورة الكهف).

2. **قسم المعايشة والفهم العميق (`DeepUnderstanding`):**
   * الباحث الدلالي والنفسي المباشر الذي يحلل مشاعر المستخدم ويستخرج التوجيه القرآني والنبوي المناسب.
   * بطاقات السياق التفاعلية لعرض أسباب النزول في قصة شيقة والمعاني البصرية للكلمات الغريبة.

3. **قسم إنتاجية المسلم (`MuslimProductivity`):**
   * منظم اليوم المعتمد على مواقيت الصلاة (Salah-Centric Planner) لإضافة وإدارة المهام.
   * محاكي النطاق الجغرافي الصامت في المسجد (Geofencing Simulator).
   * استعراض أذكار المستشعرات الذكية (بلوتوث السيارة، سرعة السفر، وموقع المولات).

4. **قسم المعاملات المالية والشرعية (`FinancialTools`):**
   * ماسح العقود والاتفاقيات بالذكاء الاصطناعي لرصد الشبهات الربوية واقتراح البدائل الشرعية.
   * حاسبة الزكاة الذكية المربوطة بسعر الذهب اللحظي والنصاب الشرعي.
   * حاسبة المواريث الشرعية مع التوزيع التلقائي للأنصبة والأدلة القرآنية.

5. **قسم المجتمع والجيل الجديد (`CommunityAndKids`):**
   * خريطة مرافق المساجد التشاركية وتقييم خدماتها من المصلين.
   * تحديات الختمات الجماعية الخاصة للأسر والأصدقاء مع ميزة إخفاء الأسماء إخلاصاً.
   * القصص الأخلاقية التفاعلية للأطفال (اختر مسارك بأخلاقك) لترسيخ الأمانة والعفو.

6. **قسم دراسة الجدوى والتقييم الهندسي (`FeasibilityReport`):**
   * واجهة تفاعلية لعرض كافة الميزات، مستويات الصعوبة، العوائق التقنية، والبدائل الهندسية.

## 🛠️ ثالثاً: التشغيل والتطوير المحلي

التطبيق مبني باستخدام **React 19** و **Vite** و **Tailwind CSS**:

```bash
# تثبيت الحزم البرمجية
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء المشروع للإنتاج
npm run build

# معاينة البناء
npm run preview
```
