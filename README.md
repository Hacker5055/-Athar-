# تطبيق أثَر (Athar App) 🌿

تطبيق إسلامي حديث ذكي يركز على **التخصيص، الذكاء الاصطناعي، والجانب العملي التفاعلي** لخدمة المسلم في يومه وعباداته وفهمه للقرآن والسنة، مع تجنب تكرار النمط التقليدي للتطبيقات الإسلامية.

---

## دراسة الجدوى التقنية والتنظيمية للميزات

### أولاً: الميزات القابلة للإضافة والتطبيق الفوري (Feasible Features)
1. **خطة مراجعة بنظام التكرار المتباعد (Spaced Repetition):**
   - *سبب القابلية:* يمكن تطبيقها باستخدام خوارزميات شهيرة مثل (SM-2 المستخدمة في Anki وSuperMemo)، حيث يتم تتبع أخطاء الحفظ وجدولة الآيات بمرونة.
2. **الربط البصري والذهني للآيات (الخرائط الذهنية):**
   - *سبب القابلية:* تصنيف موضوعي معتمد على هيكل بيانات شجري أو رسومي، وتصاميم بصرية ممتازة وسريعة في واجهات المستخدم.
3. **الباحث الدلالي والنفسي للقرآن والسنة (Semantic Search):**
   - *سبب القابلية:* استخدام نماذج التضمين النصي (Vector Search / Text Embeddings) لمطابقة مشاعر المستخدم (حزن، قلق، ظلم) مع الآيات والأحاديث الداعمة.
4. **التفسير التفاعلي وبطاقة السياق:**
   - *سبب القابلية:* ربط الآيات بأسباب النزول الموثوقة والمعاني البصرية للكلمات الغريبة في بطاقات عصرية سهلة التصفح.
5. **منظم اليوم المعتمد على الصلاة (Salah-Centric Planner):**
   - *سبب القابلية:* حساب مواقيت الصلاة عبر معادلات الفلك المعروفة وتوزيع المهام اليومية في الفترات الزمنية بين الصلوات.
6. **حاسبة المواريث والزكاة التفاعلية:**
   - *سبب القابلية:* قواعد فقهية ورياضية واضحة ومحددة مع ربط أسعار الذهب عبر APIs مالية مفتوحة.
7. **خريطة مرافق المساجد التفاعلية (Crowdsourced Map):**
   - *سبب القابلية:* تعتمد على خدمات الخرائط وقاعدة بيانات تشاركية لتقييم توفر مصلى سيدات، كراسي كبار السن، ودورات المياه.
8. **ختمات وتحديات العائلة والأصدقاء والقصص التفاعلية للأطفال:**
   - *سبب القابلية:* سهلة البرمجة كغرف جماعية خاصة مع سيناريوهات قصصية متفرعة (Branching Storytelling) تعزز الأخلاق الإسلامية.

---

### ثانياً: الميزات الصعبة أو المعقدة تقنياً/تنظيمياً (Challenging Features)
1. **مصحح التلاوة الصوتي للتجويد المباشر (AI Tajweed Recitation Corrector):**
   - *السبب:* يتطلب تدريب نماذج صوتية فائقة الدقة والتعقيد (Audio Processing / ASR) على مخارج الحروف، التشكيل، والمدود بدقة زمنية بالميلي ثانية مع اختلاف لكنات وأعمار القراء، والضوضاء المحيطة تؤدي لنسبة خطأ عالية قد تربك الحافظ.
2. **الوضع الهادئ التلقائي في المسجد عبر الخلفية (Geofencing Silent Mode):**
   - *السبب:* قيود أنظمة التشغيل الصارمة (iOS & Android) التي تمنع التطبيقات في الخلفية من تغيير وضع الرنين والصوت دون إذن مباشر، بالإضافة لاستهلاك البطارية وضعف إشارة الـ GPS داخل المباني الخرسانية للمساجد.
3. **الأذكار الذكية التلقائية المعتمدة على المستشعرات في الخلفية:**
   - *السبب:* القيود المفروضة على الوصول للبلوتوث والمستشعرات والشاشة مغلقة، وصعوبة التأكد بنسبة 100% أن اتصال البلوتوث هو سيارة (وليس سماعة منزلية مثلاً) مما قد يسبب إشعارات خاطئة ومزعجة للمستخدم.
4. **ماسح العقود والمعاملات المالية الشرعي (AI Legal/Sharia Contract Scanner):**
   - *السبب:* التبعات القانونية والشرعية الخطيرة لإصدار أحكام أو فتاوى آلية على العقود، واختلاف المصطلحات القانونية بين الدول مما يستلزم إشرافاً بشرياً فقهياً وقانونياً مستمراً.

## بنية تطبيق أثَر (Athar App)

تم بناء التطبيق باستخدام:
- **React 19**
- **Vite**
- **Tailwind CSS**
- **Lucide React Icons**

### الأقسام المتضمنة:
1. `QuranMemorization.jsx`: الحفظ الذكي، التكرار المتباعد، الخرائط الذهنية ومصحح التلاوة التفاعلي.
2. `DeepUnderstanding.jsx`: الباحث الدلالي الشعوري، وبطاقة السياق التفاعلية للآيات.
3. `MuslimProductivity.jsx`: منظم اليوم حول الصلوات، محاكي الجيوفنسينغ للمسجد، ونظام الأذكار المرتبط بالمستشعرات.
4. `FinancialTools.jsx`: ماسح العقود الفقهي، حاسبة الزكاة اللحظية، وحاسبة المواريث البصرية.
5. `CommunityAndKids.jsx`: خريطة خدمات المساجد، الختمات الجماعية الخصوصية، وقصص الأطفال التفاعلية.
6. `FeasibilityReport.jsx`: التقرير الهندسي المتكامل لتقييم الميزات وجدواها التقنية.
