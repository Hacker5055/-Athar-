# 📱 أثر — بروتوتايب تفاعلي (Design Prototype)

نموذج تفاعلي لتطبيق **أثر**: تطبيق إسلامي شامل (صلاة · قرآن · أذكار · قبلة · متتبع) بـ Flutter، بثلاث لغات.
الغرض من البروتوتايب: **اختبار تجربة الاستخدام والتصميم قبل كتابة كود Flutter**.

---

## التشغيل

```bash
cd prototype
python3 -m http.server 3000
# ثم افتح http://localhost:3000
```

لا يوجد build step ولا اعتماديات — HTML/CSS/JS خام.

## ما تعرضه الشاشة

```
┌──────────────┬───────────────┬──────────────┐
│ لوحة التحكم   │   الهاتف      │ ملاحظات      │
│ (لغة/مظهر/   │  (التطبيق)    │ التصميم      │
│  مدينة/طريقة) │               │ + الحالة     │
└──────────────┴───────────────┴──────────────┘
```

- **لوحة التحكم (يمين):** تغيير اللغة (AR/EN/FR) والمظهر (فاتح/داكن) والمدينة وطريقة الحساب — وتفعيل/تعطيل ملاحظات التصميم.
- **الهاتف:** التطبيق نفسه. كل شيء قابل للنقر.
- **ملاحظات التصميم (يسار):** أرقام مطابقة للدبابيس (pins) اللي بتظهر على الشاشة، بتشرح **ليه** كل عنصر مصمم كده.

## الشاشات (١٤ شاشة)

| التبويب | الشاشات |
|---|---|
| 🏠 الرئيسية | بطاقة الصلاة القادمة · شبكة المواقيت · تابع القراءة · وردي وأذكاري · إجراءات سريعة · آية اليوم |
| 📖 القرآن | فهرس ١١٤ سورة (بحث + تصفية) → قارئ السورة (نص عثماني + ترجمة + تفسير + مشغّل) + ورقة إعدادات القراءة |
| 📿 الأذكار | ١٠ تصنيفات → مجموعة أذكار بعدّاد لكل ذكر · مكتبة أدعية (١٥) · أسماء الله الحسنى (٩٩) |
| 🧭 القبلة | بوصلة حيّة + المسافة والزاوية + تنبيه المعايرة |
| ☰ المزيد | **أثري** (المتتبع) · السبحة · التقويم الهجري · الإعدادات · الأدعية · الأسماء · عن التطبيق · المصادر |

## ⚠️ ما هو **حقيقي** وما هو **تجريبي**

### ✅ حقيقي (حساب فعلي في المتصفح)
- **مواقيت الصلاة** — خوارزمية فلكية (مبنية على PrayTimes): الميل الشمسي، معادلة الوقت، زاوية الشفق، ظل العصر. بتتغير حسب المدينة والتاريخ وطريقة الحساب والمذهب.
- **التاريخ الهجري** — الخوارزمية الجدولية الكويتية.
- **اتجاه القبلة والمسافة** — الدائرة العظمى + هافرساين (زاوية القبلة للقاهرة = ١٣٦.١°، المسافة = ١٢٨٧ كم).
- **العدّاد التنازلي** — بيشتغل بالثانية على وقت المدينة المختارة.
- **البحث** — تطبيع عربي (إزالة التشكيل، توحيد الألف/الياء/التاء).
- **البوصلة** — بتقرا من `deviceorientation` لو الجهاز فيه مستشعر، وإلا فيه سلايدر محاكاة.

### 🧪 تجريبي (محتوى مختصر للعرض)
- نصوص القرآن: **١٤ سورة كاملة/جزئية** فقط (الفاتحة، البقرة ١-٥، الكهف ١-١٠، يس ١-١٢، الرحمن ١-١٠، الملك ١-٥، العصر، الكوثر، الكافرون، النصر، المسد، الإخلاص، الفلق، الناس). التطبيق الكامل هيضم المصحف كاملاً أوفلاين.
- الترجمات: EN/FR للسور المضمّنة فقط.
- التفسير: عيّنة (الفاتحة + آيات مختارة).
- الصوت: **محاكاة بصرية** — لا يوجد تشغيل فعلي.
- بيانات المتتبع: مُولّدة حتمياً (deterministic) للعرض.

## تحويل البروتوتايب إلى Flutter

| في البروتوتايب | في Flutter |
|---|---|
| `state` + `render()` | `Riverpod` + `StateNotifier` |
| `state.stack` | `go_router` + `ShellRoute` للتبويبات |
| `data.js` | `Drift` (SQLite) + `assets/db/quran.db` + FTS5 |
| `calc.js` | حزمة `adhan_dart` + حساب القبلة |
| `i18n.js` | `flutter_localizations` + ملفات ARB |
| الورقة السفلية | `showModalBottomSheet` |
| `.card`, `.btn`, … | `AtharCard`, `AtharButton`, … |

> ⚠️ **قبل كتابة أي كود محتوى:** راجع `docs/05-technical-plan-flutter.md` §3 — تراخيص المحتوى هي أكبر مخاطرة في المشروع (بعض مصادر القرآن والصوت **غير تجارية فقط**).
