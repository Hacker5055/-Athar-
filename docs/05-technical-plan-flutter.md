### حزم مقترحة لحساب المواقيت والقبلة
- **المواقيت:** `adhan_dart` — نسخة Dart محمولة من مكتبة Adhan JS المختبرة، تدعم طرق حساب متعددة، المذهب، قواعد خطوط العرض، والتعديل اليدوي، بدون اعتماديات خارجية [1](https://pub.dev/packages/adhan_dart) [5](https://pub.dev/packages/adhan_dart/example). (يوجد كذلك حزمة `adhan` [3](https://pub.dev/documentation/adhan/latest/)).
- **البوصلة:** `flutter_compass` [1](https://pub.dev/packages/flutter_compass)، أو `flutter_device_compass` كنسخة مُصانة حديثًا [6](https://pub.dev/packages/flutter_device_compass)، أو القراءة الخام من `sensors_plus` [5](https://pub.dev/packages/sensors_plus) مع حساب رياضي نقي لتعويض الميل والميل المغناطيسي [8](https://github.com/AbdeldjalilChougui/qibla_math).

> **نقطة تقنية حرجة للقبلة:** البوصلة بتقرأ **الشمال المغناطيسي**، واتجاه القبلة محسوب على **الشمال الحقيقي**. لازم تطرح/تضيف **الميل المغناطيسي (declination)** حسب الموقع والتاريخ قبل مقارنة الزاويتين، وإلا الخطأ في أوروبا وأمريكا يوصل لعشرات الدرجات.

## 2. بنية المشروع (Feature-first Clean Architecture)

```
lib/
├── main.dart
├── app/
│   ├── app.dart                 # MaterialApp.router + theme + localization
│   ├── router.dart              # go_router + ShellRoute للتبويبات
│   └── bootstrap.dart
├── core/
│   ├── theme/                   # tokens, light/dark/quran themes
│   ├── l10n/                    # ar, en, fr
│   ├── db/                      # drift database + migrations
│   ├── error/                   # failures + result type
│   ├── utils/                   # date, hijri, numbers, formatters
│   └── widgets/                 # مكوّنات مشتركة (AtharButton, AtharCard...)
└── features/
    ├── onboarding/
    ├── home/
    ├── prayer/
    │   ├── data/                # datasources (calc, prefs), repositories impl
    │   ├── domain/              # entities, repositories (abstract), usecases
    │   └── presentation/        # screens, widgets, providers
    ├── quran/
    ├── adhkar/
    ├── qibla/
    ├── tasbih/
    ├── tracker/                 # «أثري»
    ├── calendar/
    └── settings/
```

**قاعدة:** كل feature مستقلة؛ الـ `domain` لا يعرف Flutter ولا Drift. التبعيات تتدفق `presentation → domain ← data`.

## 3. مصادر البيانات **والترخيص** (أهم قسم في الملف) ⚖️

### 3.1 نص القرآن

| المصدر | الترخيص | التقييم |
|---|---|---|
| **Tanzil Project** (نص عثماني، حفص) | Tanzil Quran Text License | ✅ ممتاز كنص أساسي، راجع شروط النشر |
| **quran-json** (مجلّد مبني بمسار Python، فيه `meta/sources.json` بيوضّح مصدر وترخيص كل إصدار) | متغيّر حسب الإصدار، والمستودع بينشر فقط ما يُسمح بإعادة نشره | ✅ ممتاز — لأنه **يوثّق الترخيص لكل إصدار** [1](https://github.com/risan/quran-json) |
| **King Fahd Complex (مصحف المدينة)** | حقوق محفوظة للخط والصور وتخطيط الصفحات | ⚠️ النص مقبول، لكن **صور/خطوط/تخطيط** المصحف لها قيود |
| **fawazahmed0/quran-api** | المستودع Unlicense لكن **بدون ترخيص لكل إصدار**، ويعيد نشر أعمال محفوظة الحقوق | ⚠️ مخاطرة |
| **Quran.com API v4** | ⛔ «للاستخدام الشخصي غير التجاري فقط» ويمنع تجميع البيانات | ❌ **ممنوع** لتطبيق تجاري |

### 3.2 الترجمات والتفسير
- الترجمات الإنجليزية العامة (مثل Yusuf Ali) غالبًا متاحة، لكن **ترجمات Tanzil مسجّلة كمقيّدة**.
- **القاعدة:** لكل ترجمة/تفسير نحتفظ بملف `provenance.json` داخله: الاسم، المؤلف، المصدر، الرابط، الترخيص، تاريخ الإضافة. وشاشة «المصادر والتراخيص» في التطبيق بتعرضهم بشفافية (دي ميزة ثقة مش مجرد التزام قانوني).

### 3.3 الصوت
| المصدر | الترخيص |
|---|---|
| **MP3Quran.net** (API v3: قارئين/روايات/مصاحف/راديو) | ✅ النسخ وإعادة النشر مسموح مع ذكر المصدر [3](https://www.mp3quran.net/eng/api) |
| **Islamic Network CDN** (`cdn.islamic.net`), | ✅ إعادة نشر مجانية غير تجارية، وحقوق القارئ محفوظة [7](https://alquran.cloud/cdn) |
| **EveryAyah** | ⚠️ غير واضح — تجنّبه |
| **Al Quran Cloud API** | 🔍 راجع شروط كل إصدار قبل الاستخدام التجاري [1](https://alquran.cloud/api) |

> 🚨 **قاعدة ذهبية:** لو هتطلق نسخة مدفوعة («أثر بلس») لازم **كل** المحتوى يكون بترخيص **تجاري صريح**. أي مصدر «غير تجاري فقط» يعني إما: (1) التطبيق مجاني بالكامل وتمويله بتبرعات فقط، أو (2) شراء/ترخيص المحتوى. **القرار ده لازم يتاخد قبل كتابة سطر كود في محتوى التطبيق.**

### 3.4 الأذكار
- **حصن المسلم** (سعيد القحطاني) — مرجع أساسي، راجع شروط النشر.
- بعض واجهات الأذكار المتاحة عبر REST محلية المصدر (مثل `quran-api` ذاتي الاستضافة) بتذكر أن الأذكار من حصن المسلم + مجموعات حديث صحيحة [4](https://github.com/Wzkirbot/quran-api).
- **مهم:** كل ذكر لازم يكون عليه **تخريج** (الكتاب/الحديث/الرقم) أو يُترك.

### 3.5 المواقيت والقبلة
- **لا نحتاج مصدر بيانات نهائيًا** — كلها حسابات فلكية رياضية محلية.
- التاريخ الهجري: خوارزمية (أم القرى أو الجدولي) + **إزاحة يدوية ±1/±2 يوم** (لأن الهلال بالرؤية، والخوارزميات بتختلف).

## 6. البحث (Search)

- **FTS5** في SQLite على: نص الآية (بدون تشكيل + بدون همزات + توحيد الألف/الياء)، الترجمة، اسم السورة.
- **تطبيع النص العربي** قبل الفهرسة: إزالة التشكيل، توحيد (أ/إ/آ→ا، ى→ي، ة→ه)، إزالة التطويل.
- بحث صوتي (fuzzy) للتعامل مع أخطاء الكتابة.
- بحث بالرقم: `2:255` و`البقرة 255` و`الصفحة 42` و`الجزء 3`.

## 9. الإصدار (Release)

- **النكهات (flavors):** `dev` · `staging` · `prod`.
- **CI:** كل PR → تحليل + فحص ترخيص (`very_good_license` غير ضروري) + اختبارات + golden.
- **Fastlane:** رفع تلقائي لـ Play Console/TestFlight.
- **قائمة تحقق المتجر:** سياسة خصوصية منشورة · تصنيف المحتوى · لقطات للغات التلاتة · وصف يذكر «بلا إعلانات» و«يعمل أوفلاين» · ذكر المصادر والتراخيص.
