## 2. نموذج التنقل (Navigation Model)

- **شريط سفلي (Bottom Navigation)** بـ 5 تبويبات جذرية: الرئيسية · القرآن · الأذكار · القبلة · المزيد.
- **تنقل داخلي (Stack)** فوق كل تبويب مع زر رجوع، مع **حفظ حالة التبويب** (زي Instagram): لو رجعت للقرآن تلاقي السورة اللي كنت فيها.
- **أوراق سفلية (Bottom Sheets)** للإعدادات السريعة بدل شاشات كاملة: التفسير، اختيار القارئ، إعدادات الآية.
- **وصول عالمي:** ضغطة طويلة على أي آية → قائمة إجراءات.

```
Root Tabs (Bottom Nav)
   Home ─── Prayer (push)
   Quran ── Surah Reader (push) ── Tafsir (sheet) / Audio (sheet) / Settings (sheet)
   Adhkar ─ Category (push) ── Dhikr detail (push)
   Qibla
   More ─── Tracker / Tasbih / Calendar / Names / Settings / About
```

## 3. التدفقات الأساسية (Key Flows)

### 3.1 أول تشغيل (مهم جدًا — بيحدد الاحتفاظ)

```
فتح التطبيق
   │
   ▼
[لغة]  اختيار AR / EN / FR  ──► تغيير فوري للاتجاه RTL/LTR
   │
   ▼
[الموقع]  «اسمح بالوصول لموقعك لحساب المواقيت؟»
   │         ├── نعم ──► GPS/شبكة ──► اسم المدينة تلقائي
   │         └── لا  ──► بحث يدوي عن مدينة (قائمة مدن أوفلاين)
   │
   ▼
[طريقة الحساب]  اختيار من القائمة مع «شرح مبسط» و«الأكثر استخدامًا في بلدك»
   │            (مقترح تلقائي حسب الدولة: مصر → الهيئة المصرية، السعودية → أم القرى، فرنسا → UOIF)
   │
   ▼
[المذهب]  شافعي (افتراضي) / حنفي
   │
   ▼
[الإشعارات]  «تشغيل الأذان؟» + اختيار صوت + أوقات التذكير
   │
   ▼
[أثري]  «إيه اللي عايز تبني أثر فيه؟» → اختيار 3-5 عبادات من القائمة
   │
   ▼
الرئيسية 🎉
```

> **قاعدة تصميم:** كل خطوة لازم يكون فيها «تخطي»، ومعندناش طلب أذون إلا في سياقها الحقيقي (مش في أول شاشة).

### 3.2 يوم المستخدم (اليوم المثالي)

```
07:00  إشعار «صلاة الفجر في 15 دقيقة»
07:15  أذان ──► إشعار ثابت ──► فتح التطبيق
                ├── نقر «صليت» في بطاقة الصلاة ──► تحديث «أثري» ✅
                └── أذكار الصباح ──► عدّاد 33 ──► ✅
08:00  إشعار «وردك اليوم: 4 صفحات (سورة البقرة 22-26)»
12:30  أذان الظهر
18:20  أذان المغرب ──► أذكار المساء
22:00  إشعار «وش هتسيب أثر النهاردة؟» (ودجت/إشعار لطيف)
```

### 3.3 القراءة والحفظ

```
الرئيسية → «تابع القراءة» → القارئ
   ├── تمرير ←→ انتقال بين الصفحات/الآيات
   ├── نقر على آية → شريط إجراءات (تفسير · ترجمة · صوت · حفظ · لون · مشاركة)
   ├── زر التشغيل → اختيار القارئ → تشغيل + تمييز الآية + تكرار
   └── ختمة: شريط تقدم أعلى الشاشة يعرض «الجزء 3 من 30 · 12%»
```

### 3.4 الحفظ (وضع الحفظ — P1)

```
اختيار سورة/مجموعة آيات → وضع الحفظ
  1) «استمع» — تشغيل الآية N مرات
  2) «ردّد» — تسجيل اختياري (محلي فقط)
  3) «اختبر» — الآيات مخفية؛ اكشف عند الحاجة ← علّم «أخطأت»
  4) «راجع» — جدول مراجعة متباعدة: +1 يوم، +3، +7، +15، +30
  5) إحصاء: آيات محفوظة · دقة · موعد المراجعة الجاية
```

## 5. حالات خاصة لازم تتصمم (Edge States)

| الحالة | التصميم المطلوب |
|---|---|
| أول فتح بلا إنترنت | كل حاجة شغالة + رسالة «التحميل الاختياري للصوت يحتاج إنترنت» |
| رفض إذن الموقع | شاشة بحث يدوي عن مدينة + شرح ليه محتاجينه |
| رفض إذن الإشعارات | banner لطيف داخل التطبيق + شرح طريقة التشغيل من الإعدادات |
| جهاز بدون مستشعر بوصلة | التحويل التلقائي لطريقة الشمس + شرح مبسط |
| خط عرض عالي (صيف أوروبا) | رسالة «لا يوجد عشاء/فجر بزاوية واضحة» + قواعد بديلة |
| شاشة فاضية (مفيش علامات/ملاحظات) | رسم توضيحي + نص تشجيعي + زر إجراء |
| تحميل صوت فشل | إعادة محاولة + استمرار بدون صوت |
