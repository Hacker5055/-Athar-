## 1. القرار الحاسم: نص القرآن **ليس** في المستودع

أثر «أوفلاين أولًا»: القاعدة تُبنى على الجهاز، لكن **النص نفسه لا يُرفع إلى
git**. السببان:

1. **الترخيص** — مصادر كثيرة تسمح بالعرض داخل التطبيق وتمنع توزيع النص
   كحزمة بيانات. الفصل بين «الكود» و«البيانات» يجعل كل ملف `quran.db`
   موزّعًا قرارًا قانونيًا واعيًا، لا أثرًا جانبيًا لعملية بناء.
2. **الحجم** — النص العثماني + ترجمتان ≈ ٤ MB غير مضغوطة، وذاكرة git
   تحفظ كل نسخة إلى الأبد.

**ما في المستودع:** الكود، والأدوات، ومدقق الاستيراد.
**ما ليس فيه:** أي `quran.db` أو نص قرآني.

> ⚖️ قبل أول إصدار علني، راجع `docs/09` §5 مع من يعنيه الأمر. المدقق
> البرمجي يرفض أي مصدر لا يصرّح بالتخزين الدائم — لكنه **لا** يقرأ
> الرخصة نيابة عنك.

## 2. شكل ملف الاستيراد (`quran-import.json`)

شكل ثابت يُقرأ في `data/import/import_payload.dart`. أي تغيير يحتاج
تحديث هذا القسم، والمُحلّل، و`tool/convert_quran_json.py` معًا.

```jsonc
{
  "source": {
    "name": "quran-json (Tanzil + QuranEnc)",
    "license": "CC-BY-3.0 + QuranEnc 7 conditions",
    "url": "https://github.com/risan/quran-json",
    "allowsPermanentStorage": true,      // ← إن لم يكن true يُرفض الملف
    "author": "Tanzil Project · QuranEnc.com",
    "fetchedOn": "2026-10-18"            // اختياري
  },
  "surahs": [{
    "id": 1,                    // 1..114
    "name_ar": "الفاتحة",        // مطلوب
    "name_en": "The Opening",   // اختياري → يرجع للعربي
    "name_fr": "L'Ouverture",   // اختياري → يرجع للإنجليزية فالعربي
    "translit_en": "Al-Faatiha",// اختياري
    "revelation": "meccan",     // meccan | medinan
    "ayah_count": 7,            // مطلوب — يُطابق مع الواقع
    "bismillah_pre": true,      // اختياري (false للسورة ٩ فقط)
    "start_juz": 1,             // اختياري
    "start_page": 1             // اختياري
  }],
  "ayahs": [{
    "surah": 1, "ayah": 1,
    "text": "بِسْمِ ٱللَّهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ",
    "juz": 1, "hizb": 1, "page": 1,   // اختيارية (راجع §6)
    "sajda": false                     // اختياري
  }],
  "translations": {
    "quranenc.french_hameedullah": [
      { "surah": 1, "ayah": 1, "text": "Au nom d’Allah…" }
    ]
  }
}
```

### قواعد التحقّق (كلها تُجمع، لا يتوقّف عند أول خطأ)

| القاعدة | لماذا |
|---|---|
| الجذر كائن، و`source` كائن | الشكل الأساسي |
| **`allowsPermanentStorage === true`** | ⚖️ حارس الترخيص — `docs/05` §3.1 |
| ١١٤ سورة بالضبط | مصحف كامل أو لا شيء |
| ٦٢٣٦ آية بالضبط | رواية حفص عن عاصم |
| لا سورة مكرّرة | تكرار = ملف تالف |
| `ayah_count` يطابق عدد الآيات الفعلي لكل سورة | كشف اختلاط الروايات |
| رقم السورة في ١..١١٤ | — |
| نص الآية غير فارغ | — |
| `juz` ١..٣٠ · `hizb` ١..٦٠ · `page` ١..٦٠٤ | تقييد، لا رفض |

الفشل **لا يكتب شيئًا**: `QuranImporter.import` يعمل داخل معاملة واحدة
تُمحى كل الجداول في بدايتها، فلا وجود لقاعدة نصف ممتلئة.

## 3. المصادر

| المصدر | الاستعمال | الرخصة | التخزين الدائم |
|---|---|---|---|
| **Tanzil** (عبر [risan/quran-json](https://github.com/risan/quran-json)) | النص العثماني + أسماء السور | CC-BY 3.0 — نسخ وتوزيع كما هو، **تعديل النص ممنوع** | ✅ |
| **QuranEnc** | ترجمات (فرنسية حميد الله · إنجليزية صحيح) | ٧ شروط (ذكر المصدر، رقم الإصدار، بلا تعديل…) | ✅ |
| AlQuran.cloud | تحقّق / مراجعة | — | ✅ |
| Quran Foundation | **تحقّق فقط** — الكاش ≤ أسبوع | ⚠️ | ⚠️ |
| King Fahd Complex | ⛔ النص والصور والتخطيط مقيّدة | ⚠️ | ⛔ |
| fawazahmed0/quran-api | ⚠️ يحتاج مراجعة قبل الاعتماد | ⚠️ | ⚠️ |

> **شرط ثابت:** كل مصدر يظهر في شاشة «المصادر والتراخيص» مع اسمه
> ورخصته ورابطه — هذا شرط رخصة CC-BY و QuranEnc معًا، لا ميزة إضافية.

**لماذا `quran-json`؟** لأنه يوفّر فهرس رخص لكل ملف
(`data/meta/sources.json`) بحالة `license_status` صريحة. وأداتنا تقرأ
هذا الفهرس وتتوقّف إن لم تكن الحالة `granted`.

## 4. خطوات الاستيراد

```bash
cd app

# ١) تنزيل + تحويل (لا يلمس المستودع)
./tool/fetch_quran_data.sh --with-translations --out-dir ~/athar-data

# ٢) راجع الناتج
head -c 400 ~/athar-data/quran-import.json

# ٣) الاستيراد من داخل التطبيق (يتحقّق من الرخصة أولًا)
```

داخل التطبيق:

```dart
final result = ImportPayload.parse(await file.readAsString());
if (!result.ok) { /* اعرض result.errors */ return; }
final report = await ref.read(quranImporterProvider).import(result.payload!);
// report: ١١٤ سورة · ٦٢٣٦ آية · … في كذا ms
```

الأداء: الاستيراد معاملة واحدة بإدخالات مجمّعة (٥٠٠/دفعة) — أقل من
ثانية على هاتف متوسط، مقابل دقائق لو أُدخلت الآيات فرادى.

## 5. قاعدة البيانات

```
surah_rows        ١١٤ سورة
ayah_rows         ٦٢٣٦ آية (+ text_normalized مخزّن)
translation_rows  نص الترجمة لكل (إصدار، سورة، آية)
provenance_rows   الأصل (لشاشة المصادر والتراخيص)
bookmark_rows     (مهيّأ — يستخدمه أسبوع ٦)
note_rows         (مهيّأ — يستخدمه أسبوع ٦)

ayahs_fts         FTS5 على (surah_id, ayah, text_normalized)
translations_fts  FTS5 على (edition, surah_id, ayah, text_normalized)

idx_ayahs_juz     تسريع التنقّل بالجزء
idx_ayahs_page    تسريع التنقّل بالصفحة
```

### لماذا `text_normalized` مخزّن بدل الدالة في SQL؟

التطبيع في Dart (`domain/quran_text.dart`) لا في SQLite، لسببين:

- **ثبات النتيجة** — `remove_diacritics` وسلوك Unicode في SQLite يختلف
  بحسب إصدار المنصّة؛ التطبيع في Dart يعطي نفس الناتج على كل جهاز.
- **قابلية الاختبار** — `quran_text_test.dart` يختبره بلا قاعدة بيانات.

### البحث

| المدخل | التصنيف | الفهرس |
|---|---|---|
| «الرحمن» | `arabic` | `ayahs_fts` |
| «allah light» | `latin` | `translations_fts` |
| «Au nom d'Allah» | `latin` | `translations_fts` |
| `2:255` · «ص ٤٢» · «ج ٣» · «حزب ٧» | `reference` | لا فهرس — حلّ مباشر |

- الترتيب بـ `bm25()` (ملاءمة FTS5)، والبحث **بادئي**: `"الرحم"*`.
- تعبيرات FTS5 تُبنَى بتهريب `"` → `""` — حماية من حقن MATCH.
- سقف: ٨ كلمات · ٦٠ حرفًا للكلمة · ٥٠ نتيجة.

## 6. ⚠️ فجوات معروفة

| الفجوة | الحالة | الأثر |
|---|---|---|
| **`juz` / `hizb` / `page` غير متوفّرة** من `quran-json` | تُترك `null` → تُقيَّد إلى ١ | التنقّل بالجزء/الصفحة **غير صالح للاستخدام** حتى تُضاف طبقة تخطيط مصحف مرخّصة (مكتبة الملك فهد مقيّدة → نحتاج بديلًا) |
| `sajda` | دائمًا `false` | شارات السجود لا تظهر |
| **الاسم الفرنسي للسورة** | يرجع للإنجليزي | نصّ الواجهة الفرنسية يعرض الاسم الإنجليزي — مقبول مؤقتًا |
| الحواشي في الترجمات | تُحذف علاماتها (`[1]`/`(1)`) ولا تُستورد | لا حقل لها بعد |
| التلاوة الصوتية | لا شيء | كل الأصوات `bundled: false` حتى تُتحقَّق الرخص |

> هذه الفجوات **مقصودة ومعلنة**: أسوأ من ميزة ناقصة هي ميزة تعطي بيانات
> خاطئة عن القرآن. التنقّل بالجزء والصفحة ينتظر مصدر تخطيط موثوق.
