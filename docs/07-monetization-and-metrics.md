# 07 — الاستدامة والقياس (Sustainability & Metrics)

## 1. نموذج الاستدامة

### المبدأ الحاكم
> **لا إعلانات. لا بيع بيانات. لا إعلانات مدفونة داخل القرآن.**

### الخيارات (مرتّبة حسب الملاءمة)

| الخيار | الوصف | التقييم |
|---|---|---|
| **أ) مجاني بالكامل + تبرعات (صدقة جارية)** | زر «ادعم أثر» بتبرع اختياري | ✅ الأكثر اتساقًا مع غرض التطبيق، لكن الدخل غير مستقر |
| **ب) Freemium: «أثر بلس»** | الأساسي مجاني للأبد + ميزات متقدمة مدفوعة | ✅ مستقر — **لكن يشترط تراخيص تجارية لكل المحتوى** |
| **ج) شراء مرة واحدة (Lifetime)** | دفعة واحدة تفتح كل حاجة للأبد | ✅ محبوب جدًا في التطبيقات الدينية |
| **د) اشتراك سنوي رمزي** | سعر منخفض جدًا | ⚠️ مقبول لو السعر رمزي والقيمة واضحة |
| ❌ إعلانات | | مرفوض تمامًا |
| ❌ بيع بيانات / SDKs إعلانية | | مرفوض تمامًا |

### التوصية
**ابدأ بـ (أ) + (ج):** التطبيق مجاني بالكامل بدون إعلانات، مع **«دعم أثر»** (تبرع اختياري) و**«أثر بلس» بشراء مرة واحدة** يفتح:
- وضع الحفظ المتقدم (SRS) وإحصاءاته.
- حزم تلاوة إضافية وخلفيات مشاركة الآيات.
- ودجت متقدم + ثيمات إضافية + أصوات أذان إضافية.
- **ثيمات إضافية + أصوات أذان إضافية.**
- و**كل** المحتوى الديني الأساسي (قرآن، أذكار، مواقيت، قبلة) **مجاني للأبد بلا حدود**.

> السطر الأخير مهم: **لا نحجز عبادة وراء دفع أبدًا.** ده أخلاقي وهو كمان أقوى حملة تسويق.

## 4. ما **لا** نقيسه (احترامًا للخصوصية)

- ❌ الموقع الدقيق للمستخدم على سيرفر (الموقع يبقى على الجهاز).
- ❌ محتوى الملاحظات أو الآيات المحفوظة أو ما كتبه المستخدم.
- ❌ أي معرّف إعلاني (Advertising ID).
- ✅ فقط: عدد مرات فتح الميزات، اللغة، الثيم، إصدار التطبيق، الأعطال — **مجهولة وبإذن**.

---

## 5. خطة النمو (Go-to-Market) — مختصرة

1. **الاسم والبصرية:** اسم «أثر» سهل التذكر والمشاركة.
2. **مشاركة الآية كصورة:** أهم قناة نمو — صورة جميلة جدًا مع علامة مائية صغيرة.
3. **المحتوى:** مقال/فيديو قصير «ليه بنيت تطبيق إسلامي بلا إعلانات».
4. **المجتمعات:** جروبات المسلمين في فرنسا/المغرب/الجزائر (للفرنسية) + قنوات تليجرام إسلامية.
5. **المتاجر:** كلمات مفتاحية بـ 3 لغات + لقطات لكل لغة + ذكر «بلا إعلانات» و«أوفلاين».
6. **المراجعون:** إرسال للتطبيقات الإسلامية والمؤثرين الدينيين (بأدب وبدون إلحاح).
